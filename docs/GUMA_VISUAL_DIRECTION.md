# GUMA visual direction — Cartografia Viva

## Core idea
An original visual system where Earth is understood through movement, layers, coastlines, field patterns and navigational marks. Carybé is a cultural and artistic reference for organic forms and the relationship between people and territory, not a source to copy.

## Palette
- Deep Space: `#091722`
- Ocean: `#15364A`
- Signal turquoise: `#24C8B5`
- Horizon lime: `#B9F36B`
- Amber: `#F0B66A`
- Text: `#F0F5F3`
- Muted: `#A9BEC5`

## Visual rules
- Prefer dark, high-contrast analytical surfaces with generous spacing.
- Use original contour lines, flowing bands, abstract coastlines and orbital/navigation points.
- Use turquoise for active data, lime for the horizon/positive emphasis, amber for cautions and contextual markers.
- Avoid generic stock satellite imagery as the brand mark, generic leaf logos, copied signatures, or reproductions of Carybé paintings.
- Charts must prioritize legibility, labeled units, uncertainty and data provenance over decoration.
- Motion, if added, should be subtle and never required to understand the data.
